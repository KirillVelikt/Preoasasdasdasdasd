# Терминал Демо — NFC + QR (учебный проект)

Имитация экрана POS-терминала на Android. NFC читает UID поднесённой карты,
QR показывает демо-ссылку платежа. Оплата симулируется — деньги не списываются.

**Важно:** номер карты, срок и CVV не считываются и не хранятся — Android
не отдаёт эти данные приложению, и собирать их не предполагается.

## Сборка APK на GitHub Actions (без Android Studio)

1. Загрузите этот проект в репозиторий на GitHub.
2. Откройте вкладку **Actions** — сборка «Build APK» запустится сама после пуша
   (или вручную кнопкой **Run workflow**).
3. Дождитесь зелёной галочки, в запуске внизу будет **Artifacts → app-debug-apk**.
4. Скачайте архив, внутри — `app-debug.apk`, ставьте на телефон.

## Сборка локально

- Android Studio: File → Open → папка проекта, затем Build → Build APK(s)
- Или: `gradle assembleDebug` (нужен установленный Gradle 8.x и JDK 17)

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`

## Как проверить

1. Введите сумму
2. NFC: нажмите «Оплатить через NFC» и поднесите банковскую карту
3. QR: нажмите «Оплатить по QR-коду» — покажите QR или нажмите «Подтвердить»

## Развитие

Для реальных платежей подключите SDK платежной системы в тестовом режиме.
