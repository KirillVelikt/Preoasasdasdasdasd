# SPING TERMINAL — DEMO v0.3

Локальный демонстрационный интерфейс терминала оплаты.

## Запуск
Откройте `web/index.html` в браузере или добавьте папку `web` на статический хостинг. Для автономного использования без сети достаточно открыть HTML-файл после его загрузки.

## Что работает
- Локальные демонстрационные операции: успешная/отклонённая.
- Заказы с номером, покупателем, комментарием, датой, суммой и способом.
- Поиск по заказам и просмотр/печать демо-чека.
- Каталог товаров: добавление и удаление.
- Звуки через Web Audio, вибрация при поддержке браузером.
- Настройки терминала.
- Экспорт и импорт локальной резервной копии JSON.
- Данные сохраняются в localStorage данного браузера/устройства.

## Важно
Это не банковский POS-терминал. Нет подключения к банку, эквайрингу, NFC-оплате или реальному QR-эквайрингу; деньги не списываются. NFC/биометрия не используются для авторизации платежей. QR — только информационная ссылка. Не вводите реальные данные банковских карт.

Для реального приёма платежей требуется договор с платёжным провайдером, его официальный SDK/API, серверная проверка статуса и сертифицированное оборудование. Секретные ключи нельзя помещать в HTML или APK.

## Android
Каталог `android/` — минимальная WebView-оболочка и GitHub Actions workflow для сборки debug APK. Сам APK нужно собрать workflow после публикации проекта в GitHub (Actions → Build Android demo APK). Для установки на телефон скачайте APK из артефактов workflow.
