# Терминал Юмани — демо

Учебное приложение: экран POS-терминала с заставкой, музыкой,
оплатой по NFC и QR-коду. Все платежи — симуляция: реальные деньги
не списываются, платёжные шлюзы не используются.

## Возможности
- Заставка с фирменной музыкой при запуске
- Ввод суммы, экран оплаты
- **NFC**: поднесите банковскую карту — приложение прочитает UID и проведёт демо-платёж
- **QR**: генерация QR-кода со ссылкой на оплату (ZXing), таймер 5 минут
- Экран успеха с чеком (сумма, RRN) и звуком, автовозврат на кассу через 6 секунд
- Реалистичные отказы (недостаточно средств и т.п.) в 15% случаев

## Сборка на GitHub (без Android Studio)
1. Загрузите содержимое этой папки в свой репозиторий
2. Вкладка **Actions** — сборка запустится сама
3. Через 3–6 минут скачайте **Artifacts → app-debug-apk**
4. В архиве лежит `app-debug.apk` — ставьте на телефон

## Сборка локально
Android Studio → Open → папка проекта → Build APK.
Или в командной строке: `gradle assembleDebug`.

## Важно
Android не позволяет приложению читать номер карты, срок и CVV —
и это правильно. Данные карт не собираются и не передаются.
Для реальных платежей подключите SDK платёжной системы в тестовом режиме.
