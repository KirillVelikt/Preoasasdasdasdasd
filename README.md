# Терминал Юмани — демо (учебный проект)

Имитация экрана POS-терминала: NFC-сканирование карт, оплата по QR-коду,
заставка с музыкой, экран успеха со звоном. Реальных платежей нет —
это демо-симулятор, деньги никуда не списываются.

Приложение читает только UID карты (так устроен Android NFC API):
номер карты, срок действия и CVV не считываются и не хранятся.

## Сборка

### Через GitHub Actions (без Android Studio)
1. Создайте пустой репозиторий на GitHub (без README)
2. В папке проекта:
```
git init
git add .
git commit -m "Терминал Юмани демо"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/yumani-terminal-demo.git
git push -u origin main
```
3. Вкладка Actions → дождитесь зелёной галочки →
   скачайте Artifacts → app-debug-apk (внутри app-debug.apk)

### Через Android Studio
File → Open → папка проекта → Build → Build APK(s)

## Как пользоваться
1. Заставка «юмани» с музыкой → холостой экран
2. Введите сумму → «начать оплату»
3. На экране оплаты: поднесите карту к NFC либо нажмите
   зелёную пилюлю «нажмите для оплаты улыбкой»
4. Экран результата: чек с RRN, звук, авто-возврат на кассу
   (успех ≈ 85%, отказ ≈ 15% — для проверки обоих сценариев)

## Свои звуки
Замените файлы в `app/src/main/res/raw/`:
`jingle.wav` (заставка), `success.wav` (успех), `fail.wav` (отказ).
