# Терминал Демо (учебный проект)

Имитация POS-терминала: оплата по NFC и по QR-коду.
Все платежи — симуляция, реальные списания не выполняются.

## Сборка
Android Studio -> Open -> папка проекта -> Run.

## Как проверить
1. Введите сумму, выберите NFC или QR.
2. NFC: поднесите карту к телефону — увидите UID карты и демо-чек.
3. QR: приложение покажет QR на 5 минут, подтверждение — демо-чек.

## Развитие
Для реальных платежей подключите SDK ЮKassa (есть тестовый режим).
